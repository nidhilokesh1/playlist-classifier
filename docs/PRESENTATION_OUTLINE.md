# Slide Deck Outline (8-10 slides, ~8 minutes)
1. Title: project, team, problem number
2. Problem statement and motivation (why playlist curation is hard)
3. Dataset: source, classes, features, size, split
4. Preprocessing: why standardization (show the scaled vs unscaled table)
5. Models: Perceptron, SVM kernels, neural network (one diagram of the NN architecture)
6. Results: comparison table + per-class metrics of best model
7. Plots: training curves, confusion matrix, which classes are hard and why
8. LIVE DEMO: `python src/demo.py --random` (have a backup screenshot)
9. Conclusions, limitations, future work
10. Individual contributions (who did what)

Tips: rehearse the demo from a fresh clone; keep a terminal ready in `src/`; both members speak.
